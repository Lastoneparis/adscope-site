Support

Adding an app to track

Search the App Store by name inside AdScope and pick the result. The app is stored with its store identifier, so a later rename does not break tracking.

Adding keywords

Keywords are added per app and per storefront. The same term in two storefronts is two rows, because it is two measurements.

A refresh looks stuck

Refreshes are throttled to about one request per second and results are cached for fifteen minutes, so a large set takes a while and an immediate re-run returns the cached values. If the store starts refusing requests outright, AdScope backs off; leaving it alone for an hour is the fix, and pulling to refresh repeatedly is not.

Connecting Apple Search Ads

You need your own Search Ads API credentials from your Apple account. AdScope exchanges them for a token on device and stores them in the Keychain. The connection is read-only — campaigns are listed and reported on, never created or modified. There is a demo mode with clearly-badged fake data if you want to see the screens before connecting anything.

Exporting

Rank history exports as CSV from the app detail screen.

Anything else

Write to contact@oshi-messenger.com. Saying which app, which keyword and which storefront makes the answer much faster.

Note on the numbers. AdScope reports what the store returned when it asked. If your rank differs from what you see searching by hand, the likely causes are a different storefront, a different device index (iPhone / iPad / Mac are separate) or personalisation on your own device.
